# McpGo Swiss-Knife — MCP-сервер «швейцарский нож»

Один файл `server.js`, который даёт подключённому ИИ-клиенту пять
инструментов для работы на вашем компьютере (Windows):

| Инструмент | Что делает |
|---|---|
| `run_command` | выполняет команды PowerShell и возвращает вывод |
| `read_file` | читает файлы |
| `write_file` | пишет файлы (папки создаёт сам) |
| `list_dir` | показывает содержимое папки |
| `get_disks` | показывает диски и свободное место |

Ничего устанавливать не нужно — только Node.js (любой версии 16+).

## Проверка (на вашей Windows)

```
node server.js --selftest
```

Должно закончиться строкой `SELFTEST OK — все 5 инструментов работают.`

## Куда положить

Рекомендуется: `F:\McpGo\mcp-servers\swiss-knife\server.js`

## Как подключить к ИИ

### Вариант А. Локальный ИИ-клиент (Claude Desktop, Cursor, VS Code и т.п.)

В настройках MCP-серверов клиента добавьте stdio-сервер с командой:

```
node F:\McpGo\mcp-servers\swiss-knife\server.js
```

### Вариант Б. Облачный ИИ через Secure MCP Tunnel (раздел Tunnels в McpGo)

1. Создайте туннель на платформе (ссылка есть в заголовке раздела
   Tunnels) и получите его `id` и API-ключ.
2. В McpGo → Tunnels создайте определение:
   * цель (target) — **stdio-команда**:
     `node F:\McpGo\mcp-servers\swiss-knife\server.js`
   * при желании включите `autostart`.
3. Впишите API-ключ, нажмите **Start** и дождитесь статуса `Running`.
4. Добавьте URL туннеля в настройки MCP/коннекторов вашего облачного
   ИИ-клиента.

## Безопасность

Сервер выполняет действия **с правами вашего пользователя**. Тот, кто
подключился к серверу, может запускать команды на вашей машине —
подключайте его только к своим ИИ и только через доверенные каналы
(локальный запуск или туннель платформы с аутентификацией).

## Технические детали

* Протокол MCP (JSON-RPC 2.0, спецификация 2025-06-18) поверх stdio
  реализован вручную, зависимостей нет.
* stdout зарезервирован под протокол; журнал пишется в stderr.
* Вывод команд ограничен 1 МБ, время выполнения — до 600 секунд.
